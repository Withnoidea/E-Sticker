# 002：新便签由用户亲自贴上墙

状态：已确认

## 背景

自动找空位可以省一步，但亲手决定便签贴在哪里，是用户想保留的真实贴纸体验。

## 决策

写完短句后，由用户在墙上选定位置再贴上。系统不自动找空位，也不重新排列已经贴好的便签。下次打开墙时，便签仍在原来的位置。

首版采用「拿着纸」：先写短句，选择「去贴上」后预览跟随鼠标，在墙上单击才保存；按 Esc 可回到输入，保留短句和颜色。

v0.3.0 补充：新建文章在当前墙仍由用户亲手落贴。分类墙新便签会在汇总首页获得独立的初始位置与轻微倾斜，仅增加这张卡片，不重新排列已有便签。通过「移动到分类」转入的文章获得独立的初始分类墙位置，之后由用户调整，不挪动目标墙原有文章。见 [006：多分类墙与汇总首页](006-multiple-walls.md)。
