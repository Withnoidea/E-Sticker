# 004：墙上的便签可以叠放

状态：叠放和移开已确认；墙面设置留待后续

## 决策

允许把新便签贴到已有便签上，不因重叠阻止落贴，也不为避免遮挡而挪动其他便签。关闭再打开后，恢复各张便签的位置及叠放顺序。

用户可以拖开上层便签，让下面的纸露出来；也可以通过搜索或列表查看被挡住的便签，不必移动纸张。见 [005：墙面和列表共享便签](005-note-discovery.md)。

扩展墙面、换墙可放到设置中，不作为随手贴流程的必经步骤。两者的具体含义和是否纳入首版待确认。

## 首版默认行为

拖动并改变位置后，便签移到最上层；单击查看详情不改变层级。首版是一面固定尺寸、可滚动的墙。
