# 003：首版做轻量的 Windows 独立窗口

状态：产品形态已确认；首版采用 Rust + Win32 原生窗口

## 决策

首版打开一个独立的 Windows 应用窗口，窗口内展示便签墙。桌面挂件不属于首版。

关闭窗口即退出进程，不驻留系统托盘、不保留后台进程，也不注册全局快捷键。需要快速打开时，用户可用已有的 uTools 启动应用；首版不做专门集成。

轻量和高效是选型约束。首版用 Rust、Win32 原生输入控件和 GDI 绘制墙面，不引入浏览器运行时。采用此技术不等同于性能达标，仍以构建和实测为准。

## 验证方式

技术验证时，在使用者的 Windows 机器上记录冷启动到可输入的时间、空闲内存和分发体积，并确认关闭窗口后进程退出。

一次本机隐藏窗口冒烟中，约 99 ms 后检测到窗口及输入控件，工作集约 9.0 MiB，发布版单文件 356 KiB；此结果不是冷启动或长期空闲基准。关窗退出已验证。
