# 003：首版做轻量的 Windows 独立窗口

状态：产品形态已确认；便签墙采用 Rust + Win32 原生窗口，正文编辑采用 WebView2 容器

## 决策

首版打开一个独立的 Windows 应用窗口，窗口内展示便签墙。桌面挂件不属于首版。

关闭窗口即退出进程，不驻留系统托盘、不保留后台进程，也不注册全局快捷键。需要快速打开时，用户可用已有的 uTools 启动应用；首版不做专门集成。

轻量和高效仍是选型约束。便签墙继续用 Rust、Win32 原生控件和 GDI 绘制；正文编辑单独使用 Microsoft WebView2 承载锁定版本的离线 Vditor 资源。这样不把整个应用改成网页，但目标机器必须提供 WebView2 Evergreen Runtime；缺失时明确提示安装，不静默联网下载。应用会把编辑器资源解压到本地应用数据目录，并使用独立用户数据目录。

## 验证方式

技术验证时，在使用者的 Windows 机器上记录冷启动到可输入的时间、空闲内存和分发体积，并确认关闭窗口后进程退出。

WebView2 引入后的冷启动、工作集和发布目录体积必须单独实测，不能沿用纯原生版本的数字。关窗仍退出应用进程；正文保存必须先等待 WebView2 回传最新 Markdown，失败时保持窗口打开并提示用户。
