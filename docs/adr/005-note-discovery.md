# 005：墙面和列表共享便签

状态：搜索范围和可排序列表已确认；下文记录首版展示默认值

## 决策

保留自由摆放的墙面视图，并提供可切换的列表视图和搜索入口。搜索和列表都能找到完全被遮住的便签，打开的仍是同一张便签的详情。切换视图、搜索、排序和单纯查看详情不改变便签的位置或叠放顺序。

搜索同时查找墙面短句和 Markdown 正文；仅正文命中时，也能找到对应便签。

墙面保留纸张的手工布局：从左到右、从上到下是自然的摆放习惯，不是系统强制的网格或排列规则。列表则按文章的方式呈现同一批便签，包括没有正文的便签；即使纸张被完全遮住，也能从列表或搜索结果进入详情。查看详情不要求先定位到墙上原处，首版不把墙面定位列为必做项。

## 首版默认值

- 搜索时临时显示结果列表，每张便签只出现一次。结果显示墙面短句和正文节选，正文命中时优先截取相关位置。清空搜索后回到搜索前的视图。格式清理和词语高亮暂未实现。
- 默认按最近编辑排序，可切换为创建时间或短句排序。
