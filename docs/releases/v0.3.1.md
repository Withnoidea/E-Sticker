# E-Sticker v0.3.1 · 多墙与编辑体验升级

发布日期：2026-11-26。Windows x64 便携版，无需安装 Rust、Node.js 或 Python；正文编辑和设置需要 Microsoft Edge WebView2 Evergreen Runtime。

本次发布包含 v0.3.0 的多墙功能及 v0.3.1 的交互修复，可从 v0.2.9 直接升级。

## 主要更新

- 新增多分类墙，可按工作、学习或项目创建、重命名和删除；同一篇文章只保留一份内容，支持手动移动分类。
- 首页汇集所有未归档、未删除的文章；首页与分类墙独立保存位置和叠放层级，新文章增量加入，不重排已有便签。
- 文章列表支持分类、标签和全文筛选，可找回被遮住的便签；创建或编辑时间由新到旧，日期显示与排序字段一致，排序不改变墙面位置。
- 修复 Markdown 源码列表的回车续写：无序、有序、任务和嵌套列表保留结构，序号递增，新任务默认未勾选；空条目回车退出，支持撤销重做。
- 下拉框、编辑器菜单、悬浮提示和确认弹窗统一纸面样式，保留键盘操作、深色编辑器和最小窗口支持；删除默认取消。
- 保留三种离线 Vditor 编辑模式、本地图片、设置、自动保存、原生 PDF 导出及存储目录迁移。

## 下载与校验

从本次 GitHub Release 的附件下载：

- `E-Sticker-v0.3.1-windows-x64.zip`：完整解压后运行其中的 `E-Sticker.exe`。
- `E-Sticker-v0.3.1-windows-x64.zip.sha256`：ZIP 的 SHA-256 校验值；可与 PowerShell `Get-FileHash -Algorithm SHA256` 的结果比较。

包内还提供 `SHA256SUMS.txt`、README、更新记录、测试说明、设计文档与第三方许可。便签默认保存在本地数据目录，不随 EXE 目录移动而自动迁移。

## 升级注意

1. 关闭旧版应用，备份实际便签目录（包括 `wall.json` 与图片）和原配置目录的 `settings.json`，再启动新版；不要同时运行两个版本。
2. v1/v2 数据会兼容读取，首次保存升级前自动备份为 `wall.v1.bak` 或 `wall.v2.bak`。新数据使用 v3，旧版 EXE 无法读取；不要用降级脚本丢弃分类墙信息。
3. 删除分类墙会将所属正常及归档文章移入回收站；恢复后统一回首页默认归属，不重建被删除的分类墙，可再手动重新分类。

## 发布验证

- 44 项 Rust 单元测试与 7 组 Markdown 列表逻辑测试，检查格式及 Clippy 警告。
- 实际解压 EXE 的 12 项多墙、14 项 WebView2 编辑器和 11 项列表续写、排序及控件交互回归。
- PDF 专项检查覆盖三种编辑模式、取消后重试及中文、任务列表、表格、公式、本地图片与分页；验证导出不修改原 Markdown。
- 发布包和随附文件均提供 SHA-256 校验。自动化使用隔离测试数据，不访问真实便签；中文输入法、系统剪贴板和多屏 DPI 等手工验收边界见包内 `TESTING.md`。
